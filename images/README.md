# Screenshots

Put README screenshots here. Referenced by [`README.md`](../README.md) and [`README.zh.md`](../README.zh.md).

## Required files (for the current README)

| File | Shows |
| --- | --- |
| `preview-wechat.png` | WeChat platform: theme preview + toolbar |
| `preview-x.png` | X Article platform: Markdown-oriented preview |

## Naming

- Lowercase kebab-case: `preview-wechat.png`
- Prefer **PNG** (UI screenshots). JPEG only for heavy photos.
- No spaces, no Chinese characters in filenames.

## Size guidelines

| | Recommendation |
| --- | --- |
| Width | **960–1280 px** (looks sharp on GitHub, not huge) |
| Height | Crop to the preview panel; avoid full desktop wallpaper |
| File size | **≤ 500 KB** each ideally; keep under **1 MB** |
| Content | Use a **fictional sample note** — no private drafts, client names, or secrets |

## Tips

- Capture the MarkPress preview leaf (toolbar + article), not the whole Obsidian window if possible.
- Light theme screenshots are easier to read in the README.
- After adding files, open the README on GitHub to confirm images load.
